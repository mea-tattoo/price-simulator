## 計算方法

各補正率は合算せず、上から順に、その時点の金額へ適用する。

1. 基準価格
2. 形状補正
3. 余白補正
4. 複雑さ補正
5. カラー補正
6. 最終金額を1,000円単位に四捨五入

式:

`P1 = 基準価格 × (1 + 形状補正率)`

`P2 = P1 × (1 + 余白補正率)`

`P3 = P2 × (1 + 複雑さ補正率)`

`P4 = P3 × (1 + カラー補正率)`

`料金 = P4を1,000円単位に四捨五入`

各補正の実額も、その補正直前の金額を基準に表示する。

例: 基準¥33,000、複雑さ+15%、カラー+5%の場合:

- 複雑さ: +¥4,950
- 複雑さ適用後: ¥37,950
- カラー: ¥37,950 × 5% = +¥1,898（円表示は四捨五入）
- 補正後: ¥39,848
- 1,000円単位丸め後: ¥40,000

## 複数タトゥーと同時施術割
- 2件目以降の各タトゥーに `1箇所に施術したと仮定して計数する` チェックボックスを表示する
- チェック中のタトゥーは料金表示を `合算料金とする / Priced as one combined piece` に置き換え、グリーン・font-weight 400で表示する
- チェック中のタトゥーは計算上0円として扱い、元の個別料金を小計・合計へ加算しない
- チェック中のタトゥーは同時施術割の対象件数から除外し、対象となる別タトゥーが2件未満なら割引行自体を表示しない

- 初期状態は「1つ目のタトゥー」
- 追加後は「2つ目のタトゥー」「3つ目のタトゥー」…と連番表示
- 各タトゥーは独立して計算
- 削除後は番号を詰め直す
- 1件のみのとき削除ボタンは非表示
- 料金の下に `すべてリセット` ボタンを右端揃えで設置し、Totalから40px離す。確認ダイアログで承認された場合だけ全入力を初期状態へ戻す
- 2件以上の場合、合計から一律¥5,000を1回だけ割引
- 3件以上でも割引は増額しない

## 入力・補助表示

- 長辺・短辺は数値入力
- 初期値は空欄とし、入力例として長辺 `80`、短辺 `50` をプレースホルダー表示する
- 項目名とmm入力を横並びにする
- 長辺・短辺・余白・複雑さ・カラーなどの項目名は15pxで表示する
- デザインの複雑さの入力直下に `例` を置き、5段階の日本語例を表示する
- 複雑さの例は補正率一覧と同じ文字サイズ・色・行間に揃え、選択肢名と説明を `･･･` でつなぐ
- 複雑さの例の選択肢名は太字にせず、`非常にシンプル / シンプル / 標準 / 複雑 / 非常に複雑` に統一する
- 短辺の現在比率は `現在 62.5%` の形式で短辺入力の左に表示する
- 補助行の内容は残すが、`基準料金一覧`、`形状補正一覧` などの「○○一覧」見出しは表示しない
- 各項目の下に、全選択肢・補正率・その時点の実額を常時表示
- 補助一覧は小さく薄いグレーで表示し、行間を詰める
- 補助一覧の補正値は「項目名 / 率（%） / 補正額（円）」の3列に分け、率と金額の縦ラインを揃える
- iPhone Safariの入力時自動ズームを防ぐため、数値入力とモバイルのプルダウン文字は16px以上にする
- 入力エリアの `タトゥー #1` 見出しは17pxで表示する
- 現在該当する行だけ少し濃く表示
- 未選択表示は `---`
- 余白のみ `該当なし` を独立した選択肢として持つ
- 余白の選択肢は `該当なし / 余白が非常に多い / 余白が約半分 / 余白が少ない / 余白がほとんどない` とする
- 削除ボタンは通常ウェイト・明るい赤

## 料金

- `English` を先頭・初期表示、`日本語` を後ろに配置
- 英語版の寸法行は `60 × 50 mm (2.4 × 2.0 in)` のように、インチ換算を小数第1位・単位 `in` で併記する
- 英語の形状名は `Nearly Equal / Moderately Elongated / Elongated / Very Elongated` を使用する
- 見出しを左、`English / 日本語` の言語タブを右に同じ行で配置し、選択言語に応じて `Price / 料金` を切り替える
- `Price / 料金` の見出しはお支払い合計 / Totalと同じ24pxで表示する
- タブで言語を切り替える
- 寸法行は日本語で `サイズ：60 × 50 mm`、英語で `Size: 60 × 50 mm (2.4 × 2.0 in)` と表示し、サイズ帯名は表示しない
- 寸法・形状・余白・複雑さ・カラーの明細には、基準料金・補正率・補正額を表示しない
- `基準価格 / Base` の独立行は表示しない
- 形状 → 余白 → 複雑さ → カラーの順に、選択内容の名称だけを表示
- `補正合計` ではなく `補正後金額 / Adjusted price` を表示
- 数値は右端揃え
- 内訳は小さく薄いグレー
- タトゥー名、小計、割引、合計は、左端の文字列と右端の金額を同じ縦ラインに揃える
- タトゥー番号は、日本語は `タトゥー #1`、英語は `Tattoo #1` の形式で統一する
- 料金明細には `1,000円単位で四捨五入 / Rounded to the nearest ¥1,000` の行を表示しない
- 最終行は「補正後金額 / Adjusted price」や丸め前後の金額を表示せず、`1,000円単位で四捨五入 / Rounded to the nearest ¥1,000` の説明だけを表示する
- 同時施術割 / Same-day Discountは少し抑えたグリーン `#55A95D` で表示
- タトゥー金額・小計・同時施術割は16px系で揃え、同時施術割の文字と金額はfont-weight 400とする
- お支払い合計 / Totalは顧客提示用として28pxで大きく表示し、上余白を従来の2倍にする
- 合計を画面中央寄りまでスクロールできるよう、料金内訳後に大きめの余白を設ける
- 最下部に `assets/mea-logo-white-bg.png` のロゴ、`© Mea Tattoo Studio`、Versionを控えめに配置する
- Version表記は人やアーティストの番号に見える `artist-v...` を使わず、`Version 0.3.23` の形式にする
- フッターはリセットボタンからスマホ64px・通常72px離し、ロゴ幅はスマホ64px・通常70pxにする
- ロゴ下の末尾余白はスマホ36px・通常40pxにする
- ロゴ画像には透明度を指定せず、PNG本来の真っ黒を表示する
- 料金内訳上部の境界線は3pxの黒
- 言語タブには下線・ボーダーを表示しない
- 料金の説明明細は12px・濃いグレー `#646B74`、タトゥー名と金額は16pxで表示する
- 料金内訳の明細左端は、入力項目内の補助行の左端と同じ縦ラインに揃える
- 複数タトゥーの料金内訳ではタトゥー間に境界線を設けず、24pxの余白で区切る
- 料金内訳全体を囲む枠線は設置しない
- SubtotalとTotalの間は破線
- 言語タブの下線はタブ幅のみで、右端まで伸ばさない

## UI方針

- プロ用の高密度・低装飾な業務ツール
- 大きすぎる文字や装飾的な太字は使わない
- 画面端・入力カード間・料金内訳前後には判読に必要な余白を取る
- ページタイトルは画面幅いっぱいの黒背景・白文字ヘッダーとし、上・左右の余白と角丸を設けない
- ヘッダー直下に赤・font-weight 400で `※必ず1人ずつ計数すること。複数人の同時計数は禁止` と表示する
- その直下に同じ赤・font-weight 400で `※複数セッションの場合、原則1セッション目に一括払いとする` と表示する
- ヘッダータイトルは15px・font-weight 400で控えめに表示する
- iPhone Safari標準の上下バウンススクロールは無効化せず、そのまま維持する
- ページ上端へ引っ張った際も白い余白を見せず、黒いヘッダー背景が上方向へ続くようにする
- ヘッダーと最初のタトゥーの間には34〜38pxの余白を取る
- 入力項目の外枠は設置せず、薄いグレーの面でグルーピングする
- 数値入力・プルダウンの境界線は薄くし、項目カードとの二重枠を避ける
- 入力フォームでは2件目以降のタトゥーの直前に3pxの黒線を設け、線の前後に十分な余白を取る
- スマホで横スクロールを発生させない
- 予想金額の独立ボックスは設置しない
- 詳細な支払い時期説明枠は設けず、複数セッションの一括払い原則のみヘッダー直下の注意書きとして表示する
- HOME、予約フォーム、説明文、別ページのEnglish版は設置しない
